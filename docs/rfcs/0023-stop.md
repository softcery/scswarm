# Stop a row on demand

**What.** `scswarm stop PROJECT ROW` writes ref `refs/swarm/stop/<track>/<id>` at track tip. Row reads `stopped` until track moves or `reset`. Running worker sees ref within 1 s, kills its try, restarts its container, exits 3.

**Why.**
- CLI has no command to end a row (`src/main.rs`, `docs/spec/contract.md` CLI section). Documented hard stops end all workers of the user: `systemctl --user kill --kill-whom=all`, `pkill -f 'scswarm work '` (`docs/spec/contract.md` lines 313-314).
- Live stop of one wrong row, swarm host `sercos`, 2026-10-29 16:25: 6 manual steps over ssh. Delete track branch, `pgrep` worker by argv, `kill` it, `podman stop scswarm-0`, read journal, `scswarm reset`.
- Killed worker leaves agent running. `proc::capture` owns `podman exec` client (`src/proc.rs` lines 60-80). Only `Call::once` restarts container (`src/call.rs` lines 102-106); dead worker never reaches it. Manual `podman stop` hid this in live stop.
- Killed worker rests whole project. Signal exit maps to `Error::Failed(... row replays)` (`src/pool.rs` line 153); `serve` rests project 60 s (`src/serve.rs` line 239, `src/host.rs` line 20). Live journal: `skip project=sercos cause=row auth-standards/audit-auth-standards on slot 0: worker signal: 15 (SIGTERM): row replays`. All `sercos` rows waited 60 s.
- Fail refs hold no row. They key on track tip and `to` tip (`src/state.rs` lines 116-120): sibling push to `to` replays row (`docs/spec/contract.md` line 296).
- Land ref outside `to` merges again, no new session (`docs/spec/contract.md` line 192). After stop and fixed track, old work of stopped row lands.

**Done when.** `make e2e` starts row whose `run` step sleeps 600 s, runs `scswarm stop`, checks within 5 s: no `scswarm work` process, no process in slot container besides its sleeper, `status` reads `stopped`, no `skip` line. Push of new track tip then reads row `queued`.

## Design

### Ref and state

- `Key::stop_ref`: `refs/swarm/stop/<track>/<id>`, beside `land_ref` and `fail_refs` (`src/state.rs` lines 138-145). Target: track tip at `stop`.
- `State::Stopped`: stop ref equals current track tip. One predicate, read by `state` and worker.
- Precedence: merged, pushed, running, stopped, failed, queued or waiting. Running worker reads `running` until exit.
- New track tip clears stop, no write. `reset` deletes stop ref with land and fail refs (`src/reset.rs` lines 14-21).
- `mirror_kept` pushes it unchanged (`src/git.rs` line 86). Clone `status --tracks` reads `stopped`.

### `stop` command

1. Find row in its track, as `reset` does (`src/reset.rs` lines 44-59). If no row, exit 1.
2. Read row state. If pushed or merged, exit 1; error names `reset` and `git revert -m 1`.
3. Write stop ref.
4. Probe row lock (`lock::held`). If free, delete land ref. If held, worker deletes it.
5. Run `mirror_kept`.

Write comes before probe: worker spawned by `serve` after step 4 reads `stopped` at first tick.

### Worker

- `proc::capture` takes cancel check `&dyn Fn() -> Result<bool>`. `proc::wait` ticks with and without `timeout`; today it blocks on `child.wait()` with none (`src/proc.rs` line 112). Each `host::STOP_POLL` (1 s) it runs check. Hit: kill child, report `Exit::Stopped`. `proc` learns no git.
- `Call::once` restarts container on each return: agent dies with exec (`src/call.rs` lines 102-106).
- Backoff sleep between tries ticks on same check (`src/call.rs` line 95).
- `podman::build` and `podman::pull` run through `capture` with check (`src/podman.rs` lines 189-201, 252-261).
- `Attempt::deliver` checks before each push try (`src/work.rs` lines 195-209).
- `step::Outcome::Stopped` beside `Done` and `Spent` (`src/step.rs` lines 52-56). `Call::ask`, `Session::play`, `Slot::merge_onto`, `Attempt` pass it up. `merge_onto` aborts merge on it (`src/slot.rs` lines 119-125). `continue_on_error` turns only `Spent` into `Done` (`src/script.rs` line 108).
- On `Stopped`: release slot, delete land ref, write no fail refs, log event `stop row=<project>/<track>/<id>`, append transcript entry with fault `stopped`, exit 3.

### Exit 3

- `error::STOPPED = 3` beside `INVALID` and `FAILED` (`src/error.rs` lines 14-15).
- `pool::reap` maps code 3 to `Ended::Stopped` (`src/pool.rs` lines 133-160).
- `serve::Lane::ended` on it: no report, no rest, no end of rest (`src/serve.rs` lines 227-243). Stop = neither success nor fault: worker that never reached podman ends no fault streak.
- `work` exit codes bind across versions: release note.

## Steps

1. `state`: `Key::stop_ref`, `State::Stopped`, precedence.
2. `proc`: cancel check in `capture` and `wait`, `Exit::Stopped`.
3. `step`, `call`, `script`, `slot`: `Outcome::Stopped`, backoff tick.
4. `podman`: `build` and `pull` through `capture`.
5. `work`: cancel check from `state`, push check, land ref drop, exit 3. `error`: `STOPPED`.
6. `pool`, `serve`: exit 3 rests nothing.
7. `stop` module, `Command::Stop` in `main`, help text, man page.
8. `reset`: delete stop ref.
9. `tests/e2e.rs`: "Done when" check.
10. Docs: contract CLI, ref table, state table, exit codes, limits. Architecture invariant "Row stops on its ref", chokepoints `proc::wait` and `work::Attempt`. Drop `pkill` and `kill --kill-whom=all` hard-stop lines.

## Notes

- Latency up to 1 s per check. Merge and push run on to next check: seconds.
- Stop that loses race to push leaves row `pushed`, which ranks above `stopped`. Undo: `git revert -m 1` on `to`, as after `reset`.
- `lock::hold` blocks on slot lock (`src/work.rs` line 69) and build lock (`src/work.rs` line 245). Worker waiting there sees stop once it holds lock.
- Track push within 1 s of stop moves tip before worker checks. Worker runs on.
- Any push to track clears stop, push for another row included.
- Cost: 2 `git rev-parse` per tick per running worker: track tip, stop ref.
- `stop` runs on swarm host only. Feed fetches `refs/heads/*` alone (`docs/spec/contract.md` line 177); `mirror_kept` prunes stop ref pushed from clone.
- Hang outside a check, for example in git, has no bound, as today (`docs/spec/contract.md` line 325).
- Unverified: `podman build` killed mid-build leaves no half-written image. Expected from podman, not measured.
