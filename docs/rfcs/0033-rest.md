# Host file sets the first project rest

**What.** Host file field `rest`: seconds of the first rest after a worker fault. Absent = 60.

**Why.**
- `host::REST_FIRST` is a constant, 60 s (`src/host.rs:21`). `serve::Lane::ended` reads it (`src/serve.rs:259`). No host file field changes it.
- Invariant "Values live in config, not code" (`docs/refs/architecture.md`): poll and fetch come from the host file, rest is a tool default in `host` alone. Feed rest starts at `fetch`, worker rest at the constant.
- `make e2e`, 2026-11-08, one macOS podman machine: 418.66 s in total. Two phases kill a worker with SIGKILL on purpose and wait out the rest: 61.0 s and 61.1 s from `skip` to the next `assign`. That is 122 s, 29% of the run.
- Phases: `replays_after_a_kill_before_the_land_ref`, `resumes_after_a_kill_past_the_land_ref` (`tests/e2e.rs`).

**Done when.** `make e2e` passes with `rest: 1` in its host file, and the serve log shows each `assign` after a SIGKILL `skip` within 5 s.

## Design

- `host`: raw field `rest: Option<u64>`, top level, beside `poll`. `0` refuses: "field `rest` must be seconds, 1 or more, or stay absent". `Host::rest: Duration`, absent = 60 s. `REST_FIRST` goes.
- `serve`: `Lane::ended` takes the first rest from `Host::rest`. Doubling and the 15 min cap stay: cap = `REST_MAX.max(rest)`, as the feed does (`src/feed.rs:109`).
- A host file reload applies the new `rest` to the next fault. A rest in progress keeps its end.
- `help/host.yaml`: one example line, `rest: 60`.
- `docs/spec/contract.md`: host file field list gains `rest`; the worker fault rule reads "starts at `rest` seconds".
- `tests/e2e.rs`: `write_host` writes `rest: 1`. No new test: the field is config.

## Steps

1. Add the field, check and default in `host`. Drop `REST_FIRST`.
2. Pass `Host::rest` to `Lane::ended`.
3. Update `help/host.yaml` and `docs/spec/contract.md`.
4. Set `rest: 1` in the e2e host file. Run `make e2e` and record the total time in the pull request.

## Notes

- Unmeasured: e2e total time after the change. Expected drop is about 118 s, 2 × (61 − 1 − poll of 1 s); the other phases do not wait on a worker rest.
- A low `rest` on a host with a broken runner spawns one failing worker per project each `rest` seconds until the doubling grows it. Cap stays 15 min.
- Out of scope: rows that run `sleep 10` (`ROW_SECONDS`) in phases that act on no running row. About 140 s of the same run sits in row sleeps. Test-only change, no design: one pull request after a phase-by-phase check.
- Rejected: an environment variable or a test-only build flag for the rest. Two paths to one value; e2e would test a binary that differs from the shipped one.
